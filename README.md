# Mirai Gakuin — demo portofolio

Landing page LPK bahasa & keterampilan Jepang berbasis Tailwind — form pendaftaran, FAQ accordion, navigasi flyout.

> **Catatan:** ini **demo portofolio desain web**, bukan situs resmi lembaga.
> Nama, logo, dan isi dipakai sebagai contoh tampilan saja.

## Demo

**[https://demo-lpk-mirai-gakuin.vercel.app](https://demo-lpk-mirai-gakuin.vercel.app)**

## Isi

- `index.html` — satu halaman penuh, tanpa build step
- `assets/` — gambar, font, CSS, dan JS
- `vercel.json` — konfigurasi header & clean URL

## Menjalankan di lokal

```bash
# cukup buka index.html di browser, atau:
python -m http.server 8000
# lalu buka http://localhost:8000
```

## Teknologi

HTML + CSS + JavaScript murni (tanpa framework), responsif mobile-first.
Dirancang untuk calon klien lembaga pelatihan kerja (LPK) yang belum punya website.
